# Muhammad Hafiz Tech Consultant

A personal portfolio website for showcasing Muhammad Hafiz's technology consulting career, selected work, and private experiments.

## Run locally

From this directory:

```powershell
python -m http.server 8080
```

Open http://localhost:8080.

## Customize

Update the email address, career entries, project descriptions, and links in `index.html`. Visual styles live in `styles.css`; the small scroll-reveal interaction is in `script.js`.
